# מרכז הסיווג של התנועות

`classification-center.ts` הוא נקודת הכניסה היחידה לסיווג תנועות.

הזרימה המתוכננת היא:
1. כללי guardrail דטרמיניסטיים לדברים פיננסיים שאסור לסווג לא נכון.
2. תנועות שלא הוכרעו נשלחות ל-Gemini באצוות.
3. Gemini מחויב להחזיר JSON במבנה קשיח.
4. התוצאה כוללת קטגוריה, סוג, kind, confidence והסבר.
5. שכבת הייבוא צריכה להשתמש בנקודת הכניסה הזו במקום לשמור לוגיקת סיווג מקומית.
